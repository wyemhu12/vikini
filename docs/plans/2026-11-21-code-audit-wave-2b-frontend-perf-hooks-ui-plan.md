### 1. Mục Tiêu (Goal) & Out of Scope (What We're NOT Doing)

#### Mục tiêu (Goal)

Xử lý dứt điểm toàn bộ lỗi hiệu năng 60fps, điều kiện tranh chấp (concurrency/race condition), rò rỉ tài nguyên (timer/XHR/listener), đăng ký Zustand không lọc (`PERF-03`), mất dữ liệu đồng bộ client, và lỗi nuốt exception thiếu phản hồi UI trên tầng Frontend của Vikini sau khi Wave 1, Wave 2A và UX/UI Audit Phase 5–6 đã hoàn tất:

- **Nhóm 2B.1 — Chat Stream Controller Concurrency & `ChatApp` Wiring**: Khử double-fetch khi chọn hội thoại và khi tạo New Chat, khóa race condition khi chuyển hội thoại/unmount (`loadAbortRef` + `activeConvIdRef` + `prevConversationIdRef` cập nhật đồng bộ cùng guard `controller.signal.aborted`/`abortControllerRef.current !== controller` ngay sau `await createConversation()`), sửa lỗi `finally` đè `abortControllerRef` của stream mới, đưa `ensureConversationExists(controller)` vào `try/finally` (không kẹt `isStreaming=true` và không mất `input`), bề mặt hóa lỗi mạng trước token đầu tiên (`setStreamError` + `toast.error`), bổ sung flush `decoder.decode()` + xử lý `\r\n\r\n` + frame cuối trong SSE reader, tuần tự hóa `syncPartialMessage` trước `reloadMessagesAfterStream` trong `cancelStream(true)`, nối `renameConversationFinal` và `contextMessagesCount` thật vào `ChatApp.tsx`, đồng thời kéo `useChatStreamExecution.ts` từ 355 dòng xuống `<= 320` dòng (đạt chốt `TC-13 <= 350`).
- **Nhóm 2B.2 — Chat 60fps Re-Render Elimination, Composer, Voice & File Upload**: Khôi phục hiệu lực `React.memo(ChatBubble)` bằng callback ổn định (bỏ 5 inline arrow trong `ChatMessagesArea` và bổ sung 4 điểm bọc callback nội bộ trong `ChatBubble` kèm guard `safeMessage.id` cho `onSpeak`), bọc `React.memo(ChatMessagesArea)` + ổn định hóa `useTTS` và `useImageGenController`, hoist `REMARK_PLUGINS`/`REHYPE_PLUGINS_*` ra cấp module ở `BubbleMarkdown.tsx`; lazy-load `FileLightbox` trong `InputForm.tsx`; khắc phục thrashing 5 global `window` listeners, lỗi `"[object Object]"` từ `String(body.error)`, thiếu `logger.error`/bilingual `toast.error`, neo hủy XHR/timer/retry theo `shouldClearQueue(prevId, conversationId, isSelfInitiated)` + `uploadSessionIdRef` (giữ sống upload tự khởi tạo ở New Chat và dừng hẳn multi-file loop khi đổi hội thoại/unmount), đưa `useFileUpload.ts` (470 dòng) xuống `<= 300` dòng bằng cách tách `fileUploadHelpers.ts`; sửa stale closure + race restart `R1->R2`/double `getUserMedia`/Strict Mode trong `useSpeechRecognition.ts`, cập nhật đồng bộ `inputRef.current = next` trong `InputForm.tsx`, và thay raw English `{sttError}` trong tooltip `VoiceButton.tsx` bằng chuỗi dịch song ngữ.
- **Nhóm 2B.3 — Unscoped Zustand Selectors (`PERF-03`) & NovelCrafter Client Reliability**: Chuyển toàn bộ **19 tệp nguồn (20 điểm gọi)** `use*Store()` không selector đã xác minh (gồm cả `LanguageUpdater.tsx`) sang atomic selectors / `useShallow` (kèm đồng bộ 5 test mock với object/fn hoisted ổn định và chốt tĩnh `TC-14` quét toàn bộ `src/`); chấm dứt re-render 60fps ở đỉnh `NovelcrafterStudioApp` bằng leaf component `NovelcrafterStreamingCard` đọc trực tiếp `useNovelcrafterStreamStore`; xóa triệt để lỗi mất dữ liệu do `queuedByStory` mồ côi khi `sendPut` reject trong `storySyncCoordinator.ts` (và giữ `<= 400` dòng); bổ sung unmount cleanup cho cả 3 timer (`saveTimerRef`, `retryTimerRef`, `draftThrottleTimerRef`) + guard `if (isUnmountedRef.current) return false;` hậu `await coordinator.enqueueSave` (và reset Strict Mode) trong `useStoryPersistenceLifecycle.ts`.

#### 6.1 Chat Stream Concurrency & `ChatApp` Call Site

// Caller: ChatApp.tsx
const chat = useChatStreamController({
  isAuthed,
  selectedConversationId,
  setSelectedConversationId: setSelectedConversationIdAndUrl,
  createConversation: createLandingConversation,
  refreshConversations,

// Inside useChatStreamExecution.ts (New Chat concurrency guard):
const ensureConversationExists = async (controller: AbortController): Promise<string | null> => {
  if (selectedConversationId) {
    activeConvIdRef.current = selectedConversationId;
    return selectedConversationId;
  }
  setCreatingConversation(true);
  try {
    const conv = await createConversation?.();
    if (
      isUnmountedRef.current ||
      controller.signal.aborted ||
      abortControllerRef.current !== controller
    ) {
      return null; // Never hijack selectedConversationId if switched/aborted mid-flight
    }
    const convId = conv?.id || null;
    if (convId) {
      activeConvIdRef.current = convId;
      prevConversationIdRef.current = convId;
      setSelectedConversationId?.(convId);
    }
    return convId;
  } finally {
    setCreatingConversation(false);
  }
};
