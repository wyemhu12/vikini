## Technical Plan

### 1. Mục Tiêu (Goal) & Out of Scope (What We're NOT Doing)

#### Mục Tiêu (Goal)

Cho phép người dùng dán trực tiếp liên kết chia sẻ công khai (**Anyone with the link can view**) của **Google Docs**, **Google Sheets**, và **Google Slides** vào khung chat Vikini để **tất cả 12 mô hình AI** trong `SELECTABLE_MODELS` (`src/lib/core/modelRegistry.ts:41-215`) tự động đọc và phân tích nội dung ngay trong lượt chat:

1. **Tự động phát hiện & phân giải trước khi định tuyến provider** tại `src/app/api/chat-stream/chatStreamCore.ts`:
   - Phát hiện, chuẩn hóa, khử trùng lặp và giới hạn tối đa **3 liên kết/tin nhắn** (`MAX_GOOGLE_DOCS_LINKS_PER_MESSAGE = 3`) cho `docs.google.com/document/d/{ID}`, `docs.google.com/spreadsheets/d/{ID}`, và `docs.google.com/presentation/d/{ID}` (hỗ trợ cả biến thể `/u/{n}/`, query `?tab=...` và `?gid=...` / `#gid=...`).
2. **Chiến lược xuất dữ liệu theo năng lực mô hình & fallback cho tệp lớn (kể cả tài liệu chứa ảnh siêu phân giải `7168×9600`)**:
   - **Mô hình hỗ trợ Native PDF** (Gemini `3.5 Flash-Lite`, `4 Hydrogen`, `4 Neon`; Claude `5.5 Haiku`, `5.5 Sonnet` qua Direct Anthropic hoặc OpenRouter fallback):
     - **Google Docs / Slides**: tải qua Google Web Export (`export?format=pdf`), áp dụng trần dung lượng luồng (`20 MB` cho Gemini/Anthropic Direct, `15 MB` cho OpenRouter Claude, và tổng trần `25 MB/lượt`). Nếu PDF vượt trần, quá hạn (`12s`), hoặc hỏng magic bytes `%PDF-`, **tự động fallback** sang `export?format=txt` kèm ghi chú rõ ràng rằng ảnh nhúng đã bị lược bỏ.
   - **Mô hình chỉ nhận văn bản cho PDF** (DeepSeek V4.1 Flash / V4 Pro / V3.2, Grok 4.7, GLM 5.2, Groq GPT-OSS 120B, Strata Local):
     - **Google Docs / Slides**: tải thẳng `export?format=txt` (nhanh, không tốn băng thông ảnh, tránh `export?format=md` vì Google nhúng ảnh base64 cực lớn) và **tuyệt đối không** chèn `inlineData` vào Strata Local (tránh kích hoạt `StrataUnsupportedInputError("LOCAL_IMAGES_UNSUPPORTED")` tại `src/lib/features/local-llm/strataContextFit.ts:81-84`).
   - **Google Sheets (mọi mô hình)**: tải `export?format=xlsx` (trần `15 MB`, kiểm tra magic bytes `PK\x03\x04` và `validateZipArchiveSafety()` chống Zip-Bomb tại `src/lib/features/files/documentParsers.ts:43-157,252-327`) chuyển thành bảng Markdown sạch; tự động fallback sang `export?format=csv` (kèm `&gid=` nếu có) khi XLSX vượt trần hoặc lỗi.
3. **Nâng cấp Native PDF cho Claude 5.5** xuyên suốt cả liên kết Google Docs lẫn tệp PDF tải lên (`attachmentProcessor.ts`):
   - **Direct Anthropic (`ANTHROPIC_API_KEY`)**: dùng khối `type: "document"` (`BetaRequestDocumentBlock`, `source: { type: "base64", media_type: "application/pdf", data }`) trong `src/app/api/chat-stream/streaming/anthropic-stream.ts` (tách mapper thuần `anthropic-message-mapper.ts`).
   - **OpenRouter Claude Fallback**: dùng khối `type: "file"` (`file: { filename, file_data: "data:application/pdf;base64,..." }`) kèm `plugins: [{ id: "file-parser", pdf: { engine: "native" } }]` trong `src/app/api/chat-stream/streaming/openai-stream.ts`.
   - Fallback liền mạch về `extracted_text` / `extractDocumentText()` nếu tệp PDF vượt trần hoặc không hợp lệ.
4. **Bảo mật SSRF đa lớp, xử lý liên kết riêng tư & phản hồi UI song ngữ**:
   - Module `*.server.ts` riêng (`src/lib/features/chat/googleDocsResolver.server.ts`) tái sử dụng `validateSafeUrl()` (`src/lib/core/ssrfGuard.server.ts:89-153`) kết hợp allowlist tên miền chặt trên **URL gốc và mọi bước redirect**, phát hiện redirect đăng nhập `accounts.google.com` / HTTP `401`/`403` / trang HTML đăng nhập để tiêm ngữ cảnh có cấu trúc (chống AI bịa nội dung) và phát `event: meta` `{ type: "urlContext", urls }` (tái sử dụng hợp đồng sẵn có `docs/contracts.md:57,342`, không phá vỡ schema `POST /api/messages` tại `src/app/api/messages/route.ts:52-60`), hiển thị chip trạng thái song ngữ tại `SourceLinks.tsx`.

#### Out of Scope (What We're NOT Doing)

- **KHÔNG triển khai Google OAuth / Google Drive API (`drive.readonly`) cho tài liệu riêng tư (Option B)**: Người dùng vẫn cần bật chia sẻ công khai _"Anyone with the link can view"_ hoặc tải tệp lên trực tiếp.
- **KHÔNG thay đổi schema cơ sở dữ liệu Supabase / không tạo SQL migration**: Không lưu bản sao Google Docs vào bảng `files` hay Supabase Storage (xem phân tích đánh đổi ở mục 3).
- **KHÔNG hỗ trợ URL xuất bản dạng `/document/d/e/2PACX-.../pub` hoặc link Google Drive thư mục / file nhị phân tổng quát (`drive.google.com/file/d/...`)**: Chỉ xử lý 3 loại tài liệu Google Workspace công khai (`document`, `spreadsheets`, `presentation`) có `{docId}` chuẩn `/d/{ID}`.
- **KHÔNG gửi `export?format=md`** cho Google Docs (tránh phình base64 ảnh nội tuyến).
- **KHÔNG bật OpenRouter paid OCR plugins** (`mistral-ocr`, `cloudflare-ai`) cho các model non-Claude (tránh phát sinh phụ phí $2/1.000 trang và độ trễ OCR).
- **KHÔNG chỉnh sửa luồng Novelcrafter Studio (`/api/novelcrafter/stream`)** hay Image Studio (`/api/generate-image`).

### 3. Assumptions & Cross-Task Dependencies

#### Verified Assumptions (`[SRC]` / `[URL]`)

1. **Kiến trúc hiện tại của `POST /api/chat-stream`**:
   - Auth (`auth()`), kiểm tra hạn mức ngày (`checkDailyMessageLimit`), rate limit Redis (`consumeRateLimit`), và giới hạn payload request (`1 MB` mặc định) đã chạy trước khi gọi `handleChatStreamCore` (`src/app/api/chat-stream/route.ts:40-100`).
   - `maxDuration = 800` trên Vercel Pro (`src/app/api/chat-stream/route.ts:6`), nên ngân sách tải Google Docs tối đa `20s` tổng lượt (`12s` mỗi request) hoàn toàn an toàn trong trần thực thi serverless.
2. **Thứ tự xử lý ngữ cảnh và `fileIds` trong `chatStreamCore.ts`**:
   - `handleChatStreamCore` gọi tuần tự `buildMessageContext` (`src/app/api/chat-stream/chatStreamCore.ts:186-192`) → `processAttachments` (`src/app/api/chat-stream/chatStreamCore.ts:195-206`) → nối `chartProtocol` (`src/app/api/chat-stream/chatStreamCore.ts:225`) → `createProviderStream` (`src/app/api/chat-stream/chatStreamCore.ts:311-326`).
   - Với `Regenerate` và `Edit`, phía client gửi lại nội dung tin nhắn người dùng `prevUserMsg.content` / `newContent` qua `coreSend()` (`src/app/features/chat/components/hooks/useChatMessageActions.ts:203-210,230-237`), nên phân giải liên kết từ `content` của lượt hiện tại tự động hoạt động cho cả **Send**, **Edit**, và **Regenerate**.
3. **Hành vi `Strata Local` (Context Window động, `promptBudgetTokens` theo `thinkingLevel`, & cấm `inlineData`)**:
   - `toStrataMessages()` ném `StrataUnsupportedInputError("LOCAL_IMAGES_UNSUPPORTED")` nếu lượt hiện tại chứa bất kỳ `part.inlineData` nào (`src/lib/features/local-llm/strataContextFit.ts:81-84`).
   - `buildMessageContext` với `{ skipSlidingTrim: isLocalModel }` (`src/app/api/chat-stream/chatStreamCore.ts:186-192`) dùng `STRATA_DEFAULTS.RAW_CONTEXT_CEILING_TOKENS = 128000` (`src/app/api/chat-stream/contextBuilder.ts:73-96`), nên `messageContext.currentTokenCount` cộng dồn **toàn bộ lịch sử** lên tới `128K` tokens (vốn sẽ được `fitStrataPrompt()` cắt bớt ở phía sau để nhường chỗ cho lượt hiện tại).
   - Ở phía engine, `resolveStrataThinkingPlan(thinkingLevel, contextWindow)` (`src/lib/features/local-llm/strataThinking.ts:150-156,207-243`) tính `promptBudgetTokens` dựa trên `getStrataConfig().contextWindow` (`src/lib/core/strataConfig.ts:81-105`, fallback `STRATA_DEFAULTS.CONTEXT_WINDOW = 32768`), còn `fitStrataPrompt()` nhân hệ số an toàn `1.25x` khi fallback heuristic (`src/lib/features/local-llm/strataContextFit.ts:242-243`) và ném `StrataContextOverflowError` nếu chỉ riêng `system + currentTurn` vượt `promptBudgetTokens` (`src/lib/features/local-llm/strataContextFit.ts:290-295`).
   - Do đó, ngân sách văn bản Google Docs cho Strata Local **BẮT BUỘC** tính từ `Math.floor(plan.promptBudgetTokens / 1.25)` và **chỉ trừ token lượt hiện tại** (`sysPrompt + chartProtocol` + tin nhắn `user` cuối sau `processAttachments` + buffer `1024`), **tuyệt đối không** trừ `messageContext.currentTokenCount` (tránh bỏ đói 0 token trên hội thoại dài lẫn tránh `StrataContextOverflowError` ở Turn 1 với `thinkingLevel = "high"` + tệp đính kèm).
4. **Hợp đồng `urlContext` sẵn có trên toàn stack (Zero-Breaking Reuse & Chống Ghi Đè SSE)**:
   - `docs/contracts.md:57,342` đã định nghĩa `urlContext?: Array<{ retrievedUrl: string; status: string }>`.
   - `POST /api/messages` (`src/app/api/messages/route.ts:52-60`) đã allowlist đúng `{ retrievedUrl: safeHttpUrlSchema, status: z.string().max(100) }` (tối đa `100` mục).
   - Client đã có sẵn toàn bộ ống dẫn state cho `urlContext`: `src/app/features/chat/components/hooks/useChatStreamReader.ts:82-87` → `src/app/features/chat/components/hooks/useChatPartialPersistence.ts:144,162` → `src/lib/features/chat/streamProtocol.ts:132-135` → `src/app/features/chat/components/ChatMessagesArea.tsx:296` → `src/app/features/chat/components/ChatBubble.tsx:110`.
   - Do `src/app/features/chat/components/hooks/useChatStreamReader.ts:82-87` dùng `setStreamingUrlContext(urls)` (ghi đè toàn bộ thay vì nối), `processUrlContextMetadata()` (`src/app/api/chat-stream/streaming/post-processing.ts:77-123`) phải gộp `initialUrlContext` + native `urlContextMetadata` (khử trùng lặp theo `retrievedUrl`) và **không phát** frame `event: meta` `urlContext` thứ hai khi `nativeUrls.length === 0`. Đồng thời `savePartialOnce()` ở cả 5 stream engine phải kèm `initialUrlContext` để không mất chip khi client đóng tab giữa stream.
5. **Tương thích ngược với các bài test hiện hữu**:
   - `src/app/api/chat-stream/attachmentProcessor.test.ts:97-159` kiểm thử rằng tệp lịch sử `spec.pdf` có sẵn `extracted_text` vẫn tiêm văn bản `extracted_text` khi chạy với model `claude-3-7-sonnet` (và không mock `downloadFileBytes`).    - `src/app/api/chat-stream/chatStreamCore.test.ts:91-96` mock `processAttachments` chỉ trả về `{ contents, sysPrompt }` (không có `remainingTokens` / `pdfBytesUsed`), vì vậy `chatStreamCore.ts` phải dùng fallback `??` an toàn khi đọc hai trường mới này.
   - `src/app/api/chat-stream/streaming/gemini-stream.test.ts:26` mock `processUrlContextMetadata: () => undefined`, vì vậy `src/app/api/chat-stream/streaming/gemini-stream.ts:904` phải kiểm tra `Array.isArray(processedUrlContext)` trước khi sử dụng (fallback sang `initialUrlContext ?? 6. **Không cần biến môi trường mới**: Không phụ thuộc bất kỳ `.env` mới nào ngoài các key đã khai báo trong `docs/architecture.md:224-239`.

##### A. Model Capability Helper (`src/lib/core/modelRegistry.ts`)

```typescript
export type PdfCapability = "gemini" | "anthropic-direct" | "openrouter-claude" | "text-only";

export function getModelPdfCapability(
  modelId: unknown,
  options?: { hasAnthropicApiKey?: boolean }
): PdfCapability {
  const raw = String(modelId || "")
    .trim()
    .toLowerCase();
  if (!raw) return "text-only";

  // 1. OpenRouter-prefixed Claude IDs (e.g. "anthropic/claude-sonnet-5.5", "anthropic/claude-haiku-5.5")
  // ALWAYS route via OpenRouter (src/app/api/chat-stream/chatStreamCore.ts:539-541) -> 15 MB cap
  if (raw.startsWith("anthropic/claude")) {
    return "openrouter-claude";
  }

  // 2. Direct/canonical/legacy Claude IDs ("claude-haiku-5-5", "claude-sonnet-5-5", "claude-3-7-sonnet")
  // MUST use nullish coalescing AND safe `typeof process !== "undefined"` guard since modelRegistry.ts
  // is shared with client bundles (src/lib/core/modelRegistry.ts:2)
  if (raw.startsWith("claude-")) {
    const hasAnthropicKey =
      options?.hasAnthropicApiKey ??
      (typeof process !== "undefined" ? Boolean(process.env?.ANTHROPIC_API_KEY) : false);
    return hasAnthropicKey ? "anthropic-direct" : "openrouter-claude";
  }

  // 3. Gemini chat models — inspected on raw string BEFORE normalizeModelForApi() so unknown IDs
```

#### 6.2 Security, Fallback & Edge Case Architecture

1. **SSRF Hop-by-Hop Defense (`fetchGoogleExportSafely`)**:
   - `redirect: "manual"`, `credentials: "omit"`, `maxRedirects = 5`.
   - Trước **mỗi** `fetch(currentUrl)`:
     1. Kiểm tra `parsed.protocol === "https:"`, **từ chối** nếu `parsed.username !== ""` hoặc `parsed.password !== ""` hoặc `(parsed.port !== "" && parsed.port !== "443")` (chặn URL chứa userinfo và cổng phi chuẩn như cổng `8443`).
     2. Kiểm tra `isGoogleAuthRedirectHost(hostname, pathname)` (`accounts.google.com`, `accounts.youtube.com`, `workspace.google.com`, hoặc path `/ServiceLogin`, `/v3/signin`) ➔ hủy body và trả `{ ok: false, kind: "private" }`.
     3. Kiểm tra `isAllowedGoogleExportHost(hostname)` (chỉ cho phép `docs.google.com`, `drive.google.com`, `drive.usercontent.google.com`, hoặc subdomain hợp lệ `*.googleusercontent.com`) ➔ từ chối bất kỳ host nào khác (`ssrf_blocked`).
     4. Gọi `await validateSafeUrl(currentUrl)` (`src/lib/core/ssrfGuard.server.ts:89-153`) để kiểm tra DNS không trỏ vào IP nội bộ / loopback / cloud metadata `169.254.169.254` / IPv4-mapped IPv6.
   - Khi nhận `301`/`302`/`303`/`307`/`308`: hủy `response.body?.cancel().catch(() => {})` trước khi đi bước tiếp theo.
2. **Streaming Byte Cap, Pre-Download Size Guard & Timeout Cleanup**:
   - **Pre-download size check tại `src/app/api/chat-stream/attachmentProcessor.ts:31-175`**: Trước khi gọi `downloadFileBytes()` (`src/lib/features/files/fileService.server.ts:490-509`) cho PDF tải lên trên Claude, kiểm tra `typeof f.size_bytes === "number" && f.size_bytes > 0 && (f.size_bytes > maxPdfBytes || f.size_bytes > ctx.remainingPdfBytes)`. Nếu đã vượt trần theo metadata DB, bỏ qua tải nhị phân (tránh nạp tệp `50 MB` vào RAM rồi vứt bỏ) và rơi thẳng sang `extracted_text` (vẫn kiểm tra lại `result.bytes.length` sau khi tải trong trường hợp `f.size_bytes` thiếu hoặc lệch).
   - Kiểm tra `Content-Length` trước khi đọc stream; đọc `response.body.getReader()` theo từng chunk và gọi `await reader.cancel().catch(() => {})` ngay khi `totalBytes > maxBytes`.
   - Ngân sách kích thước:
     - `MAX_PDF_BYTES_DIRECT = 20 * 1024 * 1024` (`20 MB` cho Gemini & Direct Anthropic).
     - `MAX_PDF_BYTES_OPENROUTER = 15 * 1024 * 1024` (`15 MB` cho OpenRouter Claude, tương đương `~20 MB` base64).
     - `GEMINI_INLINE_PDF_THRESHOLD_BYTES = 15 * 1024 * 1024` (`<= 15 MB` gửi thẳng `inlineData`; `15–20 MB` tải lên Gemini Files API kèm `waitForGeminiFileActive(name, 15000, signal)` + đăng ký `tempGeminiFileNames` xóa trong `finally`).
     - `MAX_TOTAL_PDF_BYTES_PER_TURN = 25 * 1024 * 1024` (`25 MB` tổng PDF của cả lượt gồm tệp đính kèm + Google Docs; liên kết sau tự hạ cấp sang `txt` nếu cạn ngân sách PDF lượt).
     - `MAX_XLSX_BYTES = 15 * 1024 * 1024` (`15 MB`); `MAX_TEXT_BYTES = 2 * 1024 * 1024` (`2 MB`).
   - Timeout: `PER_REQUEST_TIMEOUT_MS = 12_000` (`12s`), `TOTAL_RESOLVE_TIMEOUT_MS = 20_000` (`20s`). Mọi `setTimeout` và `signal.addEventListener("abort", ...)` được dọn sạch trong `finally` bằng `clearTimeout` và `removeEventListener`.
3. **Magic Bytes, Login-Page Detection & Fallback Matrix**:
   - **PDF**: bắt buộc 5 byte đầu là `%PDF-` (`0x25 0x50 0x44 0x46 0x2D`) và `Content-Type` không phải `text/html`. Nếu nhận `text/html` → kiểm tra dấu hiệu trang đăng nhập Google → `GOOGLE_DOC_PRIVATE`. Nếu vượt byte cap / timeout / sai magic bytes / `uploadToGemini` hoặc `waitForGeminiFileActive` thất bại → tự động gọi `export?format=txt` (trạng thái `GOOGLE_DOC_TEXT_FALLBACK` / `GOOGLE_SLIDES_TEXT_FALLBACK`), ghi rõ chú thích lược bỏ ảnh. Nếu trả `401`/`403`/redirect `accounts.google.com` hoặc `404` → không gọi fallback TXT vô ích (ngoại trừ retry 1 lần bỏ `&tab=` khi `400`/`404` có `tab`).
   - **XLSX**: bắt buộc 4 byte đầu là `PK\x03\x04` (`0x50 0x4B 0x03 0x04`) → chuyển qua `parseXlsxWithExcelJs(bytes, maxChars)` (`src/lib/features/files/documentParsers.ts:252-327`, đã có sẵn `validateZipArchiveSafety()`). Nếu vượt `15 MB`, Zip-Bomb, hoặc parse trả `null` → tự động fallback `export?format=csv` (kèm `&gid=` nếu có, trạng thái `GOOGLE_SHEET_CSV_FALLBACK`).
   - **TXT / CSV**: giải mã UTF-8, gọi `stripNulCharacters()`, loại bỏ BOM `\uFEFF`, kiểm tra `isBinaryCorruptText()`, từ chối trang HTML đăng nhập (`/^<!doctype\s+html\b|^<html\b/i` → `GOOGLE_DOC_PRIVATE`), cắt gọn an toàn bằng `estimateCharBudget(remainingTokens)` (`src/lib/utils/tokenEstimate.ts:49-52`).
4. **Prompt-Injection Guard & Delimiter Escaping**:
   - Thoát mọi chuỗi `<<<GOOGLE_DOC_DATA_START>>>` và `<<<GOOGLE_DOC_DATA_END>>>` có trong nội dung tài liệu bên ngoài (thay bằng `[GOOGLE_DOC_DATA_MARKER]`), đồng thời sanitize tên tài liệu từ `Content-Disposition` qua `sanitizeFilename()` (`src/lib/features/files/fileValidation.ts:87-96`) + loại bỏ `<<<`/`>>>`.

   - **Timeline 3 — Concurrency / Parallel Multi-Link Budget Race**:
