### 1. Mục Tiêu (Goal) & Out of Scope (What We're NOT Doing)

#### Mục Tiêu (Goal)

Hoàn tất hai đợt cuối của cuộc kiểm toán UX/UI toàn diện cho Vikini 3.0 (tiếp nối Phase 1 + Phase 2 đã hoàn thành):

- **Phase 3 (Wave 3 — Accessibility Sâu `axe-core` = 0 & Mobile Ergonomics)**:
  1. Xóa sạch 100% lỗi `axe-core` live: nested `<main>` (`AuthShell`), `aria-allowed-role` (`MobileNavDrawer`), `scrollable-region-focusable` (`BubbleMarkdown`, `ChapterEditorWorkspace`, `PromptStudioXmlPreview`), `heading-order` (`PersonaList`, `PersonaManager`, `GemManager`, `KnowledgePanel`, hạ cấp heading Markdown trong `BubbleMarkdown`), và `image-redundant-alt` (thẻ template trong `Canvas`).
  2. Chuyển 4 Modal / Lightbox tự chế sang Radix `Dialog` có Focus Trap, ESC, `aria-modal`, `DialogTitle`, `aria-describedby={undefined}` khi không có `DialogDescription`, và giữ click vùng nền tối đóng modal (`ProjectSettingsModal`, `chat/FileLightbox`, `chat/ImageLightbox`, `image-gen/ImageLightbox`), đồng thời xóa dead code `ProjectSwitcher.tsx`.
  3. Bổ sung `aria-label` song ngữ qua `useLanguage()` cho toàn bộ nút icon-only (Admin, Image Studio, `SettingsModal`, Projects, `dialog.tsx`, `sheet.tsx`, `EditPanel`, `Canvas`, `FileManagerPanel`) và chuẩn hóa keyboard access / native `<button>` cho toàn bộ `<div/span/article onClick>` còn lại mà tuyệt đối không lồng `<button>` trong `<button>`.
  4. Hiển thị mọi nút thao tác hover-only trên Mobile/Touch & Keyboard (`opacity-100 md:opacity-0 md:group-hover:opacity-100 md:group-focus-within:opacity-100 focus-visible:opacity-100`) và nâng vùng chạm Mobile (`375px`) lên `>= 36–44px`.
- **Phase 4 (Wave 4 — IA, NovelCrafter Mobile, Admin, 4 UI States & Bilingual/Token Hygiene)**: 5. Tối ưu NovelCrafter Mobile `375px` (thu gọn mặc định `Phân cảnh Chương` chỉ khi `isMobileLayout` — `viewportWidth < 768px`, bảo toàn 100% bất biến Desktop `>= 768px`), đưa `void signIn()` khỏi render body vào `useEffect` (`ImageGenStudio`, `NovelcrafterStudioApp`), thêm auth guard cho `PromptStudioApp`, sửa `<AlertDialogDescription>` lồng `<div>`/`<input>` và `<AnimatePresence mode="wait">` bọc 3 con song song trong `ImageGenStudio`, thêm loading/disabled + `toast.error` trên `/auth/signin`. 6. #### 6.6 `SignInPage` — Alias `handleGoogleSignIn`, Loading State & Bỏ qua `NEXT_REDIRECT`

```tsx
import { handleGoogleSignIn as triggerGoogleSignIn } from "./actions";

function isNextRedirectError(error: unknown): boolean {
  if (!error || typeof error !== "object") return false;
  const digest = (error as { digest?: unknown }).digest;
  return typeof digest === "string" && digest.startsWith("NEXT_REDIRECT");
}

const onGoogleSignInClick = async () => {
  if (isSigningIn) return;
  setIsSigningIn(true);
  try {
    await triggerGoogleSignIn();
  } catch (err: unknown) {
    if (isNextRedirectError(err)) return;
    logger.error("[SignInPage] Google sign-in failed:", err);
    toast.error(t("signInFailed"));
    setIsSigningIn(false);
  }
};
```
