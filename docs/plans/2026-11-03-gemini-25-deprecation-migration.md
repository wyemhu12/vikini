### 1. Mục Tiêu (Goal) & Out of Scope (What We're NOT Doing)

**Goal**: Gỡ toàn bộ phụ thuộc runtime vào `gemini-2.5-flash` / `gemini-2.5-pro` trước ngày shutdown 01/12/2026, thay bằng:

| Legacy ID          | Model thay thế          | `contextWindow` / `tokenLimit` | `maxOutputTokens` | `category`    | `supportedThinkingLevels`                     | `descKey` mới          |
| :----------------- | :---------------------- | :----------------------------- | :---------------- | :------------ | :-------------------------------------------- | :--------------------- |
| `gemini-2.5-flash` | `gemini-3.5-flash-lite` | 1,048,576                      | 65,536            | `low-latency` | `minimal`, `low`, `medium`, `high`            | `modelDescFlashLite35` |
| `gemini-2.5-pro`   | `gemini-3.8-flash`      | 1,048,576                      | 65,536            | `reasoning`   | `low`, `medium`, `high` (**không** `minimal`) | `modelDescFlash38`     |

`DEFAULT_MODEL` đổi thành `gemini-3.5-flash-lite`. Sáu nhóm việc:

1. **Registry** (`src/lib/core/modelRegistry.ts`): thay 2 entry 2.5 bằng 2 entry mới (đặt `gemini-3.5-flash-lite` ở vị trí `SELECTABLE_MODELS[0]` vì `getModelTokenLimit` fallback về phần tử đầu — `src/lib/core/modelRegistry.ts:398-401`); gỡ 2.5 khỏi `API_ALLOWED`; thêm alias `gemini-2.5-flash → gemini-3.5-flash-lite`, `gemini-2.5-pro → gemini-3.8-flash`; tra alias trong `normalizeModelForApi` bằng `Object.hasOwn` (`src/lib/core/modelRegistry.ts:372-373`) để key kế thừa từ `Object.prototype` không lọt (A18).
2. **Gỡ nhánh `thinkingBudget` 2.5 + dead code**: `src/app/api/chat-stream/streaming/gemini-stream.ts:181-185`, `src/lib/features/novelcrafter/novelcrafterStreamRunner.server.ts:192-197`, `src/app/features/chat/components/hooks/useThinkingLevel.ts:30-35,83,114,172-178`; field `thinkingBudget?: number` trong `ChatStreamParams` (`src/app/api/chat-stream/streaming/types.ts:127`); hàm `isGemini3FlashModel` không có caller (`src/app/features/chat/components/hooks/useThinkingLevel.ts:37-42`).
3. **Hardcode 2.5 + one-shot Gemini calls**: helper mới `src/lib/core/geminiSdkHelpers.ts` (`buildMinimalThinkingConfig`, `extractGeminiResponseText`) dùng chung cho 3 call site one-shot: `src/lib/core/autoTitleEngine.ts:17` (FALLBACK) + `src/lib/core/autoTitleEngine.ts:110-122` (thinkingConfig); `src/app/api/describe-image/route.ts:80-111` (`DEFAULT_MODEL` + `thinkingConfig` + đọc text bỏ thought part); `src/app/api/generate-image/route.ts:156-192` (enhancer: `DEFAULT_MODEL`, guard selectable Gemini text model, `thinkingConfig`, đọc text bỏ thought part).
4. **Hardening Gemini 3.x strict validation** (`gemini-stream.ts` + `thought-signatures.ts`): gửi model đã normalize tới API; giữ `thinkingConfig` trong `contConfig`; đảm bảo `functionResponse` luôn có `name` (+ `id` khi `functionCall` có `id`) qua helper thuần; đảm bảo part `functionCall` trong model turn của continuation luôn có `thoughtSignature` (fallback `DUMMY_THOUGHT_SIGNATURE`).
5. **Song ngữ**: thêm khóa label + desc cho 2 model mới ở `vi.ts`, `en.ts`, `useChatTranslations.ts`; xóa `modelDescFlash25` / `modelDescPro25` (chỉ được tham chiếu bởi 2 entry bị gỡ).
6. **DB + docs + tests**: migration SQL idempotent cho `rank_configs.allowed_models`; cập nhật `docs/models.md`, `docs/database-schema.md`, `docs/contracts.md`, `docs/CHANGELOG.md`; cập nhật/thêm test co-located.

**geminiSdkHelpers.ts (`[NEW]`, `src/lib/core/`, 3 caller: autoTitle, describe-image, generate-image)**:

```ts
import { ThinkingLevel } from "@google/genai";
import {
  clampGeminiThinkingLevel,
  modelSupportsThinking,
  type GeminiThinkingLevel,
} from "@/lib/core/modelRegistry";

const SDK_THINKING_LEVEL: Record<GeminiThinkingLevel, ThinkingLevel> = {
  minimal: ThinkingLevel.MINIMAL,
  low: ThinkingLevel.LOW,
  medium: ThinkingLevel.MEDIUM,
  high: ThinkingLevel.HIGH,
};

/**
 * Cheapest valid thinkingConfig for short one-shot Gemini calls (titles, prompt rewrite,
 * image description). Clamps "minimal" to the model's lowest supported level
 * (gemini-3.8-flash → LOW). Returns undefined for models without thinkingLevel support.
 */
export function buildMinimalThinkingConfig(
  modelId: string
): { thinkingLevel: ThinkingLevel } | undefined {
  if (!modelSupportsThinking(modelId)) return undefined;
  return { thinkingLevel: SDK_THINKING_LEVEL[clampGeminiThinkingLevel(modelId, "minimal")] };
}

/**
 * Reads answer text from a generateContent response. Never returns thought parts:
 * the SDK `.text` getter already skips them; the candidates fallback filters
 * `thought === true` and joins remaining string `text` parts.
 */
export function extractGeminiResponseText(resp: unknown): string;
```

`extractGeminiResponseText` thứ tự: (1) `resp.text` là function → gọi, trả nếu là string; (2) `resp.text` là string → trả; (3) `candidates[0].content.parts` là mảng → `filter(p => isRecord(p) && p.thought !== true && typeof p.text === "string").map(p => p.text).join("")`; (4) còn lại `""`. Không throw với input `null`/primitive/shape lạ (narrowing `unknown`, không `any`).
