## Technical Plan

### 1. Mục Tiêu (Goal) & Out of Scope (What We're NOT Doing)

**Lỗi (tái hiện trên trình duyệt 2026-11-11)**: mỗi lần tải `/novelcrafter`, thẻ "Scenes (Chapter Beats)" tự mở dù chương đang chọn đã có 1.662 từ. Thẻ cao khoảng 450px nên bản thảo bị đẩy xuống y≈706px trên màn hình 900px.

**Mục tiêu**

1. Thẻ Beats chỉ **tự mở** khi chương trống **và** state truyện đã "settled" (danh sách truyện đã về, không đang chờ auto-chọn truyện, state của truyện đang chọn đã hydrate xong). Trong lúc chưa settled, thẻ **đóng**.
2. Quyết định tự động được **dẫn xuất trong render** (không qua effect đọc giá trị cũ), nên không có trạng thái "kẹt" sau khi dữ liệu thay đổi.
3. Thao tác mở/đóng của người dùng được giữ cho chương đó trong truyện đó. Hook chỉ giữ **một** lựa chọn gần nhất: sang chương khác thì lựa chọn không áp dụng; quay lại đúng chương đó (khi chưa chọn gì ở chương khác) thì lựa chọn cũ có hiệu lực lại. Đổi sang truyện khác thì lựa chọn bị bỏ.
4. Gõ chữ vào bản thảo hoặc vào các ô của thẻ Beats, hoặc AI bắt đầu stream, sẽ **khóa** trạng thái hiện tại của thẻ, nên nội dung từ rỗng → có chữ không làm thẻ tự đóng. Promote bản nháp chưa lưu (`storyId: null → id mới`) chuyển lựa chọn sang **đúng** id mới đó; lựa chọn của draft không bao giờ áp sang một truyện có sẵn khác.
5. Hết cảnh báo `react-hooks/exhaustive-deps` tại `src/app/features/novelcrafter/hooks/useChapterEditorController.ts:82`, không dùng `eslint-disable`.

**Out of Scope (What We're NOT Doing)**

- Không đổi giao diện thẻ Beats, toolbar hay vị trí khối Story Bible (đó là plan bố cục riêng).
- Không đổi thứ tự/luồng tải và đồng bộ truyện; story hook chỉ **thêm** một state ghi nhận "đã hydrate truyện nào".
- Không tách nhỏ `useNovelcrafterStory.ts` (đã 423 dòng, vượt giới hạn 350 từ trước). Plan này chỉ thêm ~8 dòng vào file đó; tách file là nợ kỹ thuật riêng.
- Không lưu trạng thái mở/đóng thẻ vào storage giữa các phiên.

```ts
// useBeatsAutoOpen.ts
export interface StoryStateSettledInput {
  isAuthed: boolean;
  isLoadingConversations: boolean;
  isLoadingState: boolean;
  validStoryId: string | null;
  hydratedStoryId: string | null | undefined; // undefined = chưa hydrate lần nào
  storyCount: number;
  hasUnsavedDraft: boolean;
}

/** Pure: true khi dữ liệu truyện hiện hiển thị là dữ liệu thật của truyện đang chọn. */
export function resolveStoryStateSettled(i: StoryStateSettledInput): boolean {
  if (i.isAuthed && i.isLoadingConversations) return false; // T1: chờ danh sách truyện
  if (i.isAuthed && i.validStoryId === null && i.storyCount > 0 && !i.hasUnsavedDraft) {
    return false; // A8: sắp auto-chọn truyện
  }
  if (i.isLoadingState) return false; // đang fetch
  return i.hydratedStoryId !== undefined && i.hydratedStoryId === i.validStoryId; // T2/T4
}

interface BeatsChoice {
  storyId: string | null;
  chapterId: string;
  open: boolean;
}

export function useBeatsAutoOpen(opts: {
  storyId: string | null;
  chapterId: string;
  chapterContent: string;
  isStateSettled: boolean;
  isStreaming: boolean;
  promotedDraftStoryId: string | null;
}) {
  const { storyId, chapterId, chapterContent, isStateSettled, isStreaming, promotedDraftStoryId } =
    opts;
  const [choice, setChoice] = useState<BeatsChoice | null>(null);

  // Lựa chọn còn hiệu lực: cùng chương, cùng truyện — hoặc lựa chọn làm trên draft (null) và truyện hiện tại chính là truyện draft vừa được promote thành.
  const storyMatches =
    choice !== null &&
    (choice.storyId === storyId ||
      (choice.storyId === null && storyId !== null && storyId === promotedDraftStoryId));
  const activeChoice = choice && choice.chapterId === chapterId && storyMatches ? choice : null;
  const autoOpen = isStateSettled && chapterContent.trim().length === 0; // dẫn xuất trong render
  const beatsOpen = activeChoice ? activeChoice.open : autoOpen;

  const commit = useCallback(
    (open: boolean) => setChoice({ storyId, chapterId, open }),
    [storyId, chapterId]
  );

  const setBeatsOpen = useCallback(
    (next: SetStateAction<boolean>) => {
      commit(typeof next === "function" ? next(beatsOpen) : next);
    },
    [commit, beatsOpen]
  );

  /** Khóa trạng thái đang hiển thị (gọi khi gõ chữ). Không làm gì nếu đã có lựa chọn. */
  const lockCurrent = useCallback(() => {
    if (!activeChoice) commit(beatsOpen);
  }, [activeChoice, commit, beatsOpen]);

  // AI bắt đầu stream → khóa trước khi token đầu tiên đổi nội dung chương.
  const prevStreamingRef = useRef(isStreaming);
  useEffect(() => {
    if (isStreaming && !prevStreamingRef.current) lockCurrent();
    prevStreamingRef.current = isStreaming;
  }, [isStreaming, lockCurrent]);

  return { beatsOpen, setBeatsOpen, lockCurrent };
}
```

Vì sao giải quyết từng Finding của Audit Run 1:

- **#1 (draft restore)**: `hydratedStoryId` là `undefined` ở render đầu → chưa settled → thẻ đóng. Effect khôi phục draft set state có chữ **và** `hydratedStoryId=null` trong cùng lượt → render sau settled, `autoOpen` dẫn xuất từ nội dung mới (có chữ) → đóng. Không còn ref đọc giá trị cũ.
- **#2 (promote khi gõ)**: lần gõ đầu tiên (vào bản thảo hoặc vào ô Beats, A12) gọi `lockCurrent()` trước `onUpdateChapter` → lựa chọn `{storyId: null, open: true}`; `bindState` set `promotedDraftStoryId = newId` cùng lượt với kích hoạt truyện (A13) → lựa chọn `null` khớp đúng `newId` → thẻ giữ mở (chi tiết ở R2-1 bên dưới).
- **#3 (initial load)**: trong lúc `isLoadingConversations`, lúc chờ auto-chọn (A8), lúc `hydratedStoryId !== validStoryId` (bao gồm render ngay sau khi `validStoryId` đổi, trước khi effect fetch kịp bật `isLoadingState`) → chưa settled → thẻ đóng suốt thời gian tải. Không còn layout jump.
- **#4 (N1 không đỏ)**: Negative Probe mới ở §9 đều làm đỏ một TC cụ thể, đã mô phỏng.
- **#5**: A6 liệt kê đủ 5 caller; không còn effect "quên thao tác" nên không có vấn đề thứ tự.

Vì sao giải quyết Audit Run 2:

- **R2-1**: lựa chọn `storyId: null` chỉ khớp khi `storyId === promotedDraftStoryId`. `bindState` set `promotedDraftStoryId` trong cùng tick và trước `setActiveId` (A13), nên ngay render đầu tiên sau promote lựa chọn vẫn khớp (không nháy, không unmount ô Beats).
